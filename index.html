        Nothing is saved on either device: no cookies, no local storage, no history of what you send. Everything lives in memory and is wiped when you close or leave this page. Each session creates fresh one-time ECDH P-256 key pairs, and the pairing code is used up the first time a phone connects. Text and files are sealed with AES-256-GCM using keys only your two devices can derive, so someone who can read the HTTPS traffic to the pairing server still can’t read your data. Before anything is sent, both devices check TLS, DTLS and the key exchange. If any check fails, transfers are blocked. The PeerJS server only helps the devices find each other.
